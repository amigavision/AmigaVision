Installation on Linux

  1. ⬇️ Download Amiberry
    v8.1.5 or later for Linux, and install it.
    Why that emulator specifically? Because Amiberry is the only emulator that has implemented Amiga NTSC scaling correctly for now, and we worked with them to perfect it. Hopefully this will come to all Amiga emulators eventually.
  2. Copy the Amiberry directory to your home directory.
  3. Launch Amiberry, it will boot directly into the AmigaVision launcher.
  4. Enjoy the ultimate Amiga games & demo scene collection!

If you already have a separate Amiberry setup that you made yourself, you can rename the default.uae file to something like AmigaVision.uae and keep both available in parallel.
