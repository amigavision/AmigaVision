AmigaVision for Copperline

Download Copperline: https://copperline.dev/
Use a build with relative media lookup in its roms and harddrives folders.

Windows installer
-----------------
Run “Install on Windows.exe” and choose Copperline. Setup copies the ROM
and disk images from the package’s Amiberry folder to Copperline’s standard
data folder and installs configs/AmigaVision.toml unchanged.

The checked “Start AmigaVision when the emulator opens” option also installs
configs/default.toml. Uncheck it to keep the existing startup config; the
AmigaVision shortcut still launches the named config with --config.
Existing configs are backed up, and saves and Shared files are preserved.

Manual setup (Mac, Linux or Windows)
-----------------------------------
Copperline’s standard data folder is:

Windows: %USERPROFILE%\Documents\Copperline
Mac:     ~/Documents/Copperline
Linux:   ~/Documents/Copperline

With portable.txt beside the executable or Linux AppImage, use its folder
instead. Quit Copperline before installing.

1. Copy the contents of this package’s Amiberry/ROMs into roms in that folder.
2. Copy the contents of Amiberry/HardDrives into harddrives in that folder.
   Keep existing AmigaVision-Saves.hdf and custom Shared files on upgrades.
3. Copy Copperline/configs/AmigaVision.toml into configs in that folder.
   No path edits are needed; use the same file on all three platforms.
4. To boot AmigaVision automatically, back up any existing configs/default.toml
   and copy AmigaVision.toml to default.toml. Otherwise load AmigaVision.toml
   from Copperline, or use copperline --config /path/to/AmigaVision.toml.

The relative entries are:

rom = "AmigaVision.rom"

[copperhf]
unit0 = "AmigaVision.hdf"
unit1 = "AmigaVision-Saves.hdf"

Copperline searches for the ROM in roms and for the HDFs in harddrives when
they are not in the working directory. They are not relative to configs.
Use lowercase roms and harddrives on case-sensitive systems.

The images contain RDB partition tables and their own boot priorities.
The supplied [emulation] auto_launch = true starts the machine immediately.
An explicit --config or a local copperline.toml takes precedence over the
saved default.

Quit Copperline with Cmd+Q on Mac or Alt+Q on Windows/Linux.

Documentation: https://copperline.dev/docs/
