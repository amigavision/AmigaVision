AmigaVision for WinUAE
======================

NOTE: If you don’t absolutely *have to* use WinUAE, we highly recommend that 
      you install Amiberry instead. It does a better job at integer scaling, 
      has correct NTSC scaling, autocrop for optimal screen usage, and its 
      filters are faster and work better across a wide range of resolutions 
      and also have no scaling artifacts in both PAL and NTSC. Amiberry always
      runs the latest WinUAE code as well, so it has the same compatibility
      and accuracy on the back-end — it’s just better at rendering correctly.

Install WinUAE 6.0.3 or later if you don’t have it already. 

1. Make sure WinUAE is not running. 

2. Copy the Configurations folder from the package’s WinUAE folder into your
   WinUAE data folder, merging folders. Back up any existing default.uae 
   before replacing it. The usual destination is:

   C:\Users\Public\Documents\Amiga Files\WinUAE\

3. Copy the HardDrives and ROMs folders from the package’s Amiberry folder
   into this WinUAE data folder. The disk images and ROM are shipped only
   once in the package; both emulators use these same files.

   After copying both parts, the WinUAE folder in Users\Public should include:

   Configurations\AmigaVision.uae
   Configurations\default.uae (Don’t want AmigaVision to autostart? Skip this)
   ROMs\AmigaVision.rom
   HardDrives\AmigaVision.hdf
   HardDrives\AmigaVision-Saves.hdf
   HardDrives\Shared\
   HardDrives\listings\

   NOTE: Back up your existing AmigaVision-Saves.hdf and any files you changed 
   in Shared if this is an upgrade of an earlier AmigaVision install. 

2. Copy this package’s plugins folder into your WinUAE installation folder,
   normally C:\Program Files\WinUAE, merging folders. The shader should be at:

   C:\Program Files\WinUAE\plugins\filtershaders\direct3d\CRT-Pi-SmartRes.fx

   If you installed WinUAE elsewhere, use the folder containing winuae.exe or
   winuae64.exe instead. Accept the Windows administrator prompt if required.
   The plugins folder goes in the installation folder, *NOT* Public Documents.

3. Start WinUAE. AmigaVision will start automatically.
   F12 opens the settings while running.

If you don’t want AmigaVision to auto-start, skip copying default.uae. You can
load the identical AmigaVision.uae from WinUAE’s Configurations panel instead.

Enjoy the best of what the Amiga platform has to offer with AmigaVision!
