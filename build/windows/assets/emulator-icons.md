# Emulator selection icons

These are existing emulator icons, resized to 192 pixels for a 64 logical pixel
installer display at up to 300% scaling. The BMPs use the standard Windows
wizard background, retaining the artwork and its shadows.

- `amiberry.bmp`: `/Applications/Amiberry Current.app/Contents/Resources/data/icon.icns`
  from the installed macOS Amiberry app (https://github.com/BlitterStudio/amiberry).
- `copperline.bmp`: `/Applications/Copperline.app/Contents/Resources/copperline.icns`
  from the installed macOS Copperline app (https://github.com/CopperlineHQ/Copperline).
- `winuae.bmp`: the 256-pixel image in
  https://github.com/tonioni/WinUAE/blob/master/od-win32/resources/winuae.ico.
  WinUAE’s `tools/macos-bundle.sh` converts this same file to `WinUAE.icns`.

Artwork belongs to the respective emulator projects; these assets identify
those emulators in the AmigaVision installer.
